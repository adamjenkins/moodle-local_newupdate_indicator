# Changes

## v1.1.4

- The badge colours now follow Moodle 5.3's dark colour mode. The primary,
  secondary, success, danger, warning and info badges take their colours from
  the Moodle Design System where the theme provides it, and look the same as
  before on older Moodle versions and themes.
- The plugin now has its own icon on the Plugins overview page
  (Site administration > Plugins).
- The README now gives the correct capability name,
  `local/newupdate_indicator:manage`.
- The camp listing now shows two screenshots.

No database or capability changes. No action is required after upgrading.
